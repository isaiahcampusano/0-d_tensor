03 · TAKEAWAYS

What the shapes are telling you

01

Rank is axis count

ndim always equals the number of entries in shape.

02

Shape is a map

Each shape entry tells you how many positions exist along one axis.

03

Nesting is structure

Every dimension adds a bracket layer, while a scalar needs none.

04

Storage stays simple

Dense values live in one flat list. Shape tells us how to reconstruct the nesting.

A useful edge case: an empty list has shape (0,). Without any child values, the playground cannot infer an extra inner size such as (0, 3).
